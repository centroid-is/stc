# TwinCAT declaration-syntax probes

These fixtures drive Phase 19 (TwinCAT declaration syntax). `gvl1.st`, `gvl2.st`, `structat.st`, `structpragma.st`, `prog.st`, `action.st`, `link.st` and `fbat.st` are one-construct probes copied verbatim from the sildarvinnsla flattening work; each isolates a single construct and carries no customer logic. `action_inside.st`, `ECT.st` and `enum_attr.st` are hand-written synthetic shapes that reproduce the structure of real TwinCAT exports (ACTIONs inside a POU after METHODs, an EtherCAT GVL with `TcLinkTo` and OPC UA attributes, attributes on enum values) without any of their content. The large flattened customer sources (`st301.st`, `svncorecomponents.st` and similar) are used only as a local oracle and are never committed. None of these files ends in `_test.st`, so `stc test tests/` does not run them. Two lines are deliberately out of scope for Phase 19 and are owned by Phase 20: the bit-access line `b := w.3;` in `prog.st` and the named function-argument calls to `F_X` in `link.st`.
