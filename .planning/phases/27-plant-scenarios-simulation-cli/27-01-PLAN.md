<interfaces>
Contracts this plan creates (later plans depend on these exact names):

- `type ActionKind string` with constants `ActSet "set"`, `ActLink "link"`, `ActAnalog "analog"`, `ActTrip "trip"`, `ActSlaveState "slave_state"`, `ActDriveFault "drive_fault"`, `ActRamp "ramp"`, `ActSerialPeer "serial_peer"`.
- `type Action struct { Kind ActionKind; Path string; Value any; Slave string; Channel int; State string; StateCode int64; HasStateCode bool; LFT int; Script string; Unit string; From, To float64; Over time.Duration }`. Analog stores the number in Value as float64 and Unit as "mA", "V" or "raw". A slave ramp has Kind ActRamp, Slave/Channel/Unit set and Path empty.
- `type Expect struct { Path string; Value any; Within int; Tol float64 }`.
- `type Step struct { Index int; Line int; AtSet bool; At time.Duration; Cycle int; Action *Action; Expect *Expect }`.
- `type Scenario struct { Name, Description string; Cycles int; Steps []Step }`.
- `func Parse(data []byte, file string) (*Scenario, []diag.Diagnostic)`, `func Load(path string) (*Scenario, []diag.Diagnostic)`.
- `type Target interface { BaseTick() time.Duration; Clock() time.Duration; Tick() error; Check(a Action) error; CheckPath(path string) error; Apply(a Action) error; SetNumber(path string, v float64) error; Read(path string) (any, error) }`. Read returns JSON-style values (bool, int64, float64, string).
- `type Executor struct`, `func NewExecutor(s *Scenario, t Target) *Executor`, `(*Executor) Prepare() []diag.Diagnostic`, `(*Executor) Run(cycles int) (*Report, error)`. Pass cycles <= 0 to use the scenario or derived length (D-09).
- Report types in report.go: `Report{Name string; Cycles int; SimTimeNs int64; Steps []StepResult; Assertions []AssertionResult; Diagnostics []diag.Diagnostic; Passed bool}`, `StepResult{Index, Line, Cycle int; AtNs int64; Action string; Fired bool; Error string}`, `AssertionResult{Step int; Path string; Expected, Actual any; Cycle int; Pass bool; Message string}`, all with snake_case json tags.
</interfaces>
