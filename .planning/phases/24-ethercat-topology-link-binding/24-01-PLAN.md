<interfaces>
Export shape (`Device 1.xml`, EtherCATConfig Version 1.3):
- `EtherCATConfig/Config/Master/Info/Name` (CDATA, e.g. "Device 1 (EtherCAT)")
- `Config/Slave/Info/{Name, VendorId, ProductCode, RevisionNo, PhysAddr, Physics}`; `Config/Slave/PreviousPort/{Port, PhysAddr}`
- `Config/Slave/ProcessData/{Sm0..SmN}/{Enable, Pdo (decimal index)}`; `ProcessData/TxPdo|RxPdo` with `Index` ("#x1a00"), `Name`, `Entry/{Index ("#x0" = padding), SubIndex, BitLen, Name, DataType}`
- `EtherCATConfig/Config/ProcessImage/{Inputs,Outputs}/{ByteSize, Variable/{Name, DataType, BitSize, BitOffs}}`. Variable names: slave entries are `<slave.Name>.<[Module seg.]><pdo>.<entry>` (e.g. "ST301.A1.03 (EL1008).Channel 1.Input", "ST301.A1.09 (EL2912).Module 3 (DEVICEIO).FIELDVOLTAGE Field Voltage Status.Fieldvoltage Underrange"); slave pseudo `<slave.Name>.WcState.WcState`, `<slave.Name>.InfoData.State`, `<slave.Name>.InfoData.AdsAddr`; master pseudo `Inputs.DevState`, `Inputs.SlaveCount`, `Inputs.Frm0State`, `Inputs.Frm0WcState`, `InfoData.AmsNetId`, `InfoData.ChangeCount`.

Real ST301 counts: Device 1 = 23 slaves, Device 2 = 49, Device 3 = 34, Device 4 = 16.

Beckhoff semantics (BECKHOFF-REFERENCE section D): WcState BOOL (0 valid); InfoData.State WORD (0x8 OP); InfoData.AdsAddr = 6-byte NetId + UINT port (1001+); DevState UINT bit flags; Frm0WcState bit 0x8000 frame missing.
