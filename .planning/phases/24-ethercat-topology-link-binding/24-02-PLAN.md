    - "TIID^Device 1 (EtherCAT)^InfoData^AmsNetId" -> one Link{Member:"", Target: same string}
    - ".I1 := TIID^A^B; .I2:=TIID^A^C;" -> two links I1, I2 (whitespace-tolerant, trailing ; allowed)
    - ".p_stat_Enabled                 := TIID^...^Status^Enabled" keeps target segments with spaces and parentheses intact after trimming each segment
    - ".sub.member := TIID^X" -> Member "sub.member"

  <action>

Trim; if the value starts with "." it is the multi-member form: split on ";", skip empty items, split each item on the first ":=", member = trimmed text after the leading "." (keep inner dots), target = normalised target. Otherwise single form. Normalise a target by splitting on "^", trimming each segment, and rejoining with "^" (exact, case-sensitive segments per the match-semantics decision). Errors are plain `fmt.Errorf` values naming the offending item.
  </action>

  </acceptance_criteria>
